# 慢慢书桌

一个放在窗边的音乐书桌，陪你阅读、写字和工作。

[打开慢慢书桌](https://61-design.github.io/slow-desk/)

## 音乐与声景

6 个系列、85 首可直接播放的音乐：午夜来信、爵士乐、Lo-fi、轻节奏、原声乐和轻音乐。

- 首次打开默认选择《午夜来信》的《不问来处》，点击“播放《不问来处》”发声；再次打开恢复上次选择。
- 手机首屏提供播放按钮，下滑离开主按钮后显示底部播放条；可以生成带歌曲二维码的分享卡片，保存图片或复制链接。
- 系列按钮只浏览曲库，不切歌、不打断播放；点具体歌曲立即播放。
- 支持列表循环、随机播放、单曲循环、收藏和“不喜欢 / 恢复”。
- 轻雨、篝火、海浪和流水都能独立播放、分别调音量。从静音状态点开环境声只播放环境声；正在听音乐时，可打开环境声叠加。恢复历史偏好时仍保持静音，等待主动操作。
- 主播放器与底部播放器同步显示音乐、自然声或两者组合；音乐 / 自然声两个入口只切换浏览，不改变播放。已选声音的开关与音量集中在主播放器。
- 播放方式与定时位于选声区域之后，默认展开；仅自然声时不显示切歌、音乐循环和歌曲分享。
- 支持定时关闭和“安静模式”。
- “午夜来信”收录《不问来处》《睡到自然醒》《慵懒午后》，并提供另外三首推荐歌曲的音乐平台入口。平台歌曲需联网前往对应平台，不进入书桌播放队列。

浏览器会保存播放偏好、收藏和不喜欢列表。页面随机展示鼓励句，可以手动换一句，无需填写内容。统计模块目前未启用，不发送访问或播放数据。完成飞书接收端验证后才会配置开启，并提供关闭入口；不记录文字或搜索词。公网访问仍受 GitHub Pages 及浏览器本身的服务政策约束。

## 本地使用

下载仓库后保留 `assets` 文件夹。完整使用音乐和环境声，请运行 `python3 -m http.server 8853 --bind 127.0.0.1`，访问 `http://127.0.0.1:8853/`。

运行交互检查：`node qa/library-ui.test.cjs`。运行播放引擎检查：`node qa/player-upgrade.test.cjs`。统计逻辑检查：`node --test qa/analytics.test.cjs`。

飞书接入状态与口径见 [统计接入说明](统计接入说明.md)。
